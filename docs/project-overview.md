# DocuMind

DocuMind is a multi-tenant AI document-management SaaS.

## Main goals

- Learn production-grade .NET backend architecture
- Use Clean Architecture
- Use Vertical Slice Architecture
- Support organizations and workspaces
- Later support document upload, processing, embeddings and AI search

## Technology

- ASP.NET Core Minimal APIs
- .NET 10
- Entity Framework Core
- PostgreSQL
- pgvector
- Docker
- React and Vite frontend
